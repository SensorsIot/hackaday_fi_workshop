# had_fi_workshop
Hackaday Fault Injection 101 workshop training material

power traces and firmware extraction script - your task is to figure out timings and glitch parameters

## stm8flash_win64
stm8flash utility built for Windows(c)(tm); espstlink was disabled to avoid compilation errors

## test_firmware
stm8s test firmware source code; requires `sdcc` compiler

## glitcher_creature
glitcher firmware submodule
